# Project information

- Project: AI-Powered Job Match & Resume Analyzer (RoleFit)
- Version: 1.0.0
- Stack: React + TypeScript + Vite, Python + FastAPI, scikit-learn, pypdf, SQLAlchemy, PostgreSQL / SQLite
- Status: Portfolio-ready MVP scaffold
- Important limitation: no authentication/multi-user isolation in this MVP. Do not deploy with real resumes as a public service until authentication, authorization, retention policy, and security controls are added.
